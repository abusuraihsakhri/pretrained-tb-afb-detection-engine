VALIDATION PRINCIPLES

Metrics require their evidence.

Performance values are intentionally withheld until the trained checkpoint, frozen split manifest, software environment and evaluation outputs can be released together.

  • Slide/patient-level partitioning where identifiers permit
  • Independent test set kept separate from validation
  • Negative microscopy fields retained
  • Precision, recall, F1, AP50 and AP50–95
  • False positives per image or examined field
  • Threshold, model hash and error analysis reported
