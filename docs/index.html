The project

From image data to a reviewable result

The repository is more than a trained checkpoint. It contains the steps and tools around a model that make the work inspectable and repeatable.

  1. 01

    Dataset intake and audit

    Source manifests, label checks, duplicate detection, annotation-rule checks, and a machine-readable audit report help surface data-quality issues before training.

Reproducible workflow

What comes next for a valid evaluation

The audit has made the next scientific steps explicit. These are required before a new model result can be interpreted as an independent evaluation.

  1. Verify sources.Confirm pinned versions, licenses, class definitions, acquisition metadata, and exclusions.
  2. Correct and curate.Resolve annotation issues and exclude quarantined or license-unresolved records, without silently repairing labels.
  3. Group before splitting.Keep each patient, specimen, smear/slide, original field, and duplicate cluster together.
  4. Develop without the test set.Use training and development validation only for model and threshold selection.
  5. Evaluate once.Freeze the data, checkpoint, and threshold before locked testing; report uncertainty and source-level error analysis.

Limitations

What this work does not establish

These boundaries are part of the research record and should guide how the software and historical outputs are interpreted.

  • AFB appearance does not identify Mycobacterium tuberculosis or confirm tuberculosis.
  • The current historical metrics do not represent independent test performance; no corrected model has completed a locked test evaluation.
  • No prospective, external-site, reader, workflow, calibration, or clinical-impact validation has been completed.
  • Performance across laboratories, scanners, stain protocols, populations, and low-load specimens remains unknown.
  • Smear grading requires a validated acquisition and field-sampling protocol; detections alone are insufficient.
  • The local research log is not a regulated electronic-record audit trail.
