Acid-fast bacilli detection for digital microscopy.

A Python-based computer-vision system for detecting acid-fast bacilli in Ziehl-Neelsen microscopy images, including tiled analysis of large images and whole-slide imaging workflows.

FEATURES

Built around the complete AFB analysis workflow.

01

AFB detection

YOLO-based object detection identifies candidate acid-fast bacilli and returns bounding boxes with confidence scores.

02

Whole-slide support

OpenSlide-based workflows support tiled processing of large microscopy slides that cannot be analyzed as a single image.

03

Overlap handling

Overlapping tiles improve edge coverage, while global non-maximum suppression removes duplicate detections across tile boundaries.

04

Expert annotation

Annotation endpoints support review and collection of labeled examples for iterative dataset development and retraining.

05

Dataset tools

Utilities are included for public-data ingestion, Pascal VOC conversion, train/validation/test organization, and integrity checks.

06

Multiple compute targets

Inference and training can use NVIDIA CUDA, Apple Metal/MPS, or CPU execution depending on the available hardware.

07

FastAPI backend

A REST API provides programmatic access to image analysis and annotation workflows for local applications and integrations.

08

Research reporting

Detection counts, processing statistics, and optional field-based smear grading can be generated when the sampling protocol is known.

WORKFLOW

From slide image to reviewed detections.

The system separates data preparation, model training, inference, post-processing, and expert review so each stage can be inspected and reproduced independently.

  1. 01
    Prepare microscopy data

    Organize image and annotation sources while preserving train, validation, and test partitions.

  2. 02
    Train the detector

    Train the single-class AFB model with deterministic configuration and versioned dataset settings.

  3. 03
    Analyze images or slides

    Run direct raster inference or tiled whole-slide analysis depending on image size and format.

  4. 04
    Post-process detections

    Confidence filtering and global NMS consolidate detections across overlapping regions.

  5. 05
    Review and annotate

    Expert review can refine annotations for subsequent experiments and model iterations.

OPEN SOURCE

Designed for transparent, reproducible development.

The repository contains the source code for data preparation, training, inference, post-processing, API access, and annotation workflows. The project is intended for research and method development and should not be used as a standalone clinical diagnostic system without appropriate validation and governance.
